# 📚 Student Grade Calculator

## Description
A Student Grade Calculator built using HTML, CSS, and JavaScript to calculate total marks, percentage, grades, and pass/fail results for five subjects.

## Purpose
The purpose of this project is to practice JavaScript functions, arrays, loops, conditional statements, and DOM manipulation by building a simple student result calculator.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Enter marks for five subjects
- Calculate total marks out of 500
- Calculate percentage
- Display grades based on percentage
- Show Pass or Fail status
- Validate marks between 0 and 100
- Reset button to clear all inputs
- Simple and responsive user interface

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter marks for all five subjects.
5. Click **Calculate Result** to view the result.
6. Click **Reset** to clear the inputs and start again.

## Grading Rules
- A+: 90% and above
- A: 80%–89.99%
- B: 70%–79.99%
- C: 60%–69.99%
- D: 50%–59.99%
- E: 35%–49.99%
- F: Fail if any subject mark is below 35

*These are sample grading rules for this project and may differ from actual college rules.*
